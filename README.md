The funniest one-line warning label for a time machine, in 120 characters or fewer. `main.py` writes it to `/output/entry.txt`:

> WARNING: Only one of you may claim the refund. The other one already did.

A straight-faced safety notice about the duplicate-self hazard: only one of you may claim the refund — the other one already did.

## Run it

```sh
python3 main.py
```
